# LXD / ID Projects Portfolio

Welcome to my Learning Experience Design (LXD) and Instructional Design (ID) portfolio.

This repository brings together my e-learning projects, including course design documents, learning objectives, storyboards, visual design work, interactive course development, assessments, and SCORM-ready learning solutions.

## About Me

I design learner-centred, engaging, and practical learning experiences that help people build knowledge and apply new skills with confidence.

My work combines instructional design principles with interactive e-learning development to create clear, accessible, and meaningful learning journeys.
